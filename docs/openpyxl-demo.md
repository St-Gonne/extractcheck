# Five cells can hide a missing formula

This small comparison reads the same generated workbook with openpyxl twice.
One mode returns formulas. The other returns cached values.

Both modes find five cells at the same five coordinates. Only the first retains
the formula. A pipeline that checks cell count alone would miss the difference.

| Check | Source census | Formula mode | Cached-value mode |
| --- | --- | --- | --- |
| Nonempty cells | 5 | 5 | 5 |
| Formula cells identified | 1 | 1 | 0 |
| Cell coordinates retained | 5 | 5 | 5 |

Cached-value mode is a deliberate openpyxl feature. It is useful when you need
the saved result. It does not retain the expression that produced that result,
and it does not calculate a new result. This demo shows a setting tradeoff;
it is not a parser ranking or a reported openpyxl defect.

## Run it

From a checkout with Python 3.11 or newer:

```sh
python -m venv .venv
```

Activate the environment (`. .venv/bin/activate` on macOS/Linux or
`.venv\Scripts\Activate.ps1` in PowerShell), then run:

```sh
python -m pip install ".[demo]"
python tools/demo_openpyxl.py --output openpyxl-demo-output
```

The optional demo uses openpyxl 3.1.5. The core package still has no runtime
dependencies. Use a new output directory for each run; existing output is
never overwritten.

Read `openpyxl-demo-output/comparison.json`. It should report
`expected_tradeoff_observed: true`, five cells in each mode, and one formula
versus zero. A fresh second run should produce the same report bytes.

## What the comparison establishes

The workbook is written as deterministic OOXML independently of openpyxl.
ExtractCheck's separate source census counts the cells and formula nodes.
The two extraction runs emit contract-validated cell units with exact sheet
indices and coordinates. They share no expected counts with the census.

The report retains counts, settings, coordinates and source identity. It
contains no cell values or formula expressions. The input is generated by
the command; the command accepts no document path. The existing Python network
guard covers the run and records attempts. It is not an operating-system sandbox.

This is one workbook with one formula and a known cached result. It does not
measure correctness across a private corpus, cached-value freshness, table or
chart recovery, or retrieval quality.

## A two-minute walkthrough

1. Show the table above. Both modes have the same cell count.
2. Run the command and point to the formula counts and matching locators.
3. Explain the choice: keep formulas when auditing calculations; cached values
   alone may be enough for a different task.
4. Invite a synthetic counterexample or an independent run report through the
   repository's existing benchmark-result issue form. Never attach private files.

The useful question is which evidence the downstream task needs, then whether
the chosen extractor and settings retain it.
